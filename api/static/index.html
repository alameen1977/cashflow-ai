How it works

1

Learn from history

For every invoice, the model only uses payments that had already happened on that date — no peeking at the future.

2

Score every open invoice

Chance of paying late, expected delay, and plain-English reasons, served by a live API.

3

Automate follow-ups

An n8n workflow drafts a reminder for each invoice, firm for risky accounts and helpful for disputes.

4

Keep humans in control

Firm messages to high-value accounts wait for a manager's approval before anything is sent.
